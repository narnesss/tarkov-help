# Проверка первого отображения страниц

После сборки запустите `python3 tests/browser/serve-export.py`, затем в другом терминале
`node tests/browser/page-content.cjs`. Нужны Playwright и установленный Chromium.
При необходимости задайте `PLAYWRIGHT_MODULE` (путь к установленному пакету),
`BROWSER_EXECUTABLE` (путь к Chrome) и `TEST_BASE_URL` (адрес своего экспорта).

Тест использует отдельные пустые браузерные контексты и подменяет API локальными фикстурами:
намеренно задерживает данные, проверяет отсутствие каталога в HTML карточек,
запросы `detail`, ошибку 503 и сохранность прочих/архивных отметок после изменения выбранного квеста.
Рабочие аккаунты, серверная БД и пользовательские cookies не используются.
