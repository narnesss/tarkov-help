# Laravel 13 и кэширование

Перенести HTTP-приложение и экспорт страниц на Laravel 13, сохранив карты, квесты,
формат API, изоляцию прогресса и работающую статическую публикацию Cloudflare.
Источник разметки — Blade/PHP; готовый HTML остаётся только результатом экспорта.
Сгенерированные файлы исключаются из статистики языков GitHub через Linguist.
Общий файловый кэш: каталог публичных маршрутов и отрендеренные публичные страницы.
Инвалидация по содержимому исходников; личные API-ответы не кэшируются.
Критерии: настоящий Laravel HTTP/Artisan, Composer lock, сохранение API-контракта,
проверки CSRF/owner/CAS, 7006 маршрутов, воспроизводимый экспорт и Wrangler dry-run.
