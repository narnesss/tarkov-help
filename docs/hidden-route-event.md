# Событийная цепочка «Скрытый путь»

Источники — шесть сохранённых пользователем страниц Escape from Tarkov Wiki:
Hidden Route, A Simple Task in a Difficult Place, Extending the Operation,
Information Trail, Side Hustle и Doxed. Снимки описывают событие октября 2026 года.
Их HTML и сторонние исполняемые файлы в проект не переносятся.

Русские названия и тексты переведены по этим страницам. Официальная русская
локализация названий не подтверждена. В каталогах PvE и PvP это справочные
событийные задания; источники не уточняют доступность отдельно для каждого режима.

Добавлены шесть заданий, 12 целей и пять предметов. Игровые ID в источниках
отсутствуют, поэтому используются стабильные локальные ID с префиксом
`event-20261016-`; они не выдаются за игровые идентификаторы.
Существующие задания и ID не заменяются.

«Деанонимизация» требует принятого «Побочного заработка» (`active`), остальные
переходы цепочки требуют завершения предыдущего задания. Начальная выдача
карт доступа: одна, три и одна соответственно во втором, третьем и четвёртом
заданиях. Награды в рублях приведены без бонуса разведцентра. Для прекурсоров
используется количество 3 из таблицы квестовых предметов страницы Side Hustle.

В `public/assets/hidden-route-event` скопированы 16 доступных локальных
иллюстраций и значков. Галереи используют русские подписи и содержат ссылки
на оригиналы, атрибуцию и сведения о лицензии. Не загруженные при сохранении
страниц иллюстрации не подменяются похожими изображениями. Координаты точек
не выдумываются: схема и фотографии доступны в карточках прохождения.

Исходные записи входят в `guide/quest-patch-1150.json` и подготовленный
`content:seed`. На новом сервере штатный импорт создаёт их один раз. На уже
работающем сервере пакет `20261017-hidden-route-event.json` добавляет только
отсутствующие ссылки предметов в файловые справочники и затем обновляет
проекцию связей этих шести квестов. Операция транзакционная; повторное применение
не заменяет последующие редакторские правки. JSON остаётся в файлах контента.
