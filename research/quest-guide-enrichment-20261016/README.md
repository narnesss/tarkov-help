# Дополнение прохождений — 16 октября 2026

Проверены 21 квест в PVE и PVP. Добавлены локальные иллюстрации, русские подписи, самостоятельно сформулированные пояснения и проверенные схемы с метками. Источники и SHA-256 исходных файлов — audit.json. Материалы, требующие дальнейшей сверки, перечислены отдельно в remaining каждого квеста.

Схематические точки имеют координаты в процентах конкретного изображения; это не игровые XYZ. Для «Звонков без ответа» показано здание TerraGroup, а точное место за стойкой — на фотографии. Варианты V3 не обещают гарантированный спавн. Карты новых заданий Маяка, доступные на Tarkov.help после входа, оставлены внешними ссылками: собственные координаты не угаданы.

Миграция добавляет только gallery, guideAdditions, guideSources, externalMaps и новые записи quest-map-index. Она сверяет ID существующих целей, использует общий редакторский lock, не заменяет цели/награды/зависимости, не изменяет публикацию и пользователей. Повторное применение сохраняет редакторские правки. Новые установки получают те же материалы из quest-content.
